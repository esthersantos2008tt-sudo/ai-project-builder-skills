# AI Project Builder - Skills Database

Este repositório contém todas as skills de desenvolvimento organizadas por área.
O agente de IA consulta estas skills automaticamente ao construir projetos.

## Como Funciona

1. O usuário envia um prompt descrevendo o projeto
2. O classificador identifica as áreas relevantes
3. O agente busca as skills correspondentes neste repositório
4. As skills são injetadas como contexto no prompt do sistema
5. A IA gera código alinhado com as melhores práticas
